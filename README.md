 Brain Cancer Knowledge GraphCe projet est une application web full-stack conçue pour construire un graphe de connaissances (Knowledge Graph) à partir de la littérature scientifique biomédicale. L'application extrait les résumés d'articles de PubMed, utilise un modèle de traitement du langage naturel (NLP) pour identifier des entités pertinentes (gènes, maladies, molécules), et modélise les relations entre ces entités dans une base de données graphe Neo4j.ArchitectureL'application est construite sur une architecture microservices conteneurisée avec Docker, assurant une séparation claire des responsabilités et une facilité de déploiement.Frontend (Streamlit) : Une interface utilisateur web simple et interactive qui permet de lancer le traitement des données et de visualiser les statistiques du graphe. Elle communique avec le backend via des requêtes HTTP.Backend (API FastAPI) : Le cœur logique de l'application. Cette API REST expose des endpoints pour :Extraire les données de PubMed.Orchestrer le traitement NLP pour la reconnaissance d'entités (NER).Générer et exécuter les requêtes Cypher pour peupler la base de données graphe.Base de Données (Neo4j) : Une base de données graphe native utilisée pour stocker les entités médicales comme des nœuds et leurs relations comme des arêtes. C'est l'outil idéal pour l'analyse de réseaux complexes et la découverte de connexions cachées.Stack TechniqueOrchestration : Docker & Docker ComposeFrontend : StreamlitBackend : FastAPI (Python 3.9)Base de Données : Neo4j 4.4NLP / Machine Learning :Librairie transformers de Hugging FaceModèle NER : Kushtrim/ModernBERT-base-biomedical-nerCommunication API : Librairie requests Installation et LancementCe projet est entièrement conteneurisé. Les seules dépendances requises sur votre machine sont Git, Docker et Docker Compose.1. Prérequis (pour les utilisateurs Linux)Pour éviter les problèmes de permissions avec Docker, il est fortement recommandé d'ajouter votre utilisateur au groupe docker.# Ajouter votre utilisateur au groupe docker
sudo usermod -aG docker $USER

# Vous devrez vous déconnecter et vous reconnecter pour que ce changement soit pris en compte !
2. Cloner le Dépôtgit clone [https://github.com/VOTRE_NOM_UTILISATEUR/NOM_DU_REPO.git](https://github.com/VOTRE_NOM_UTILISATEUR/NOM_DU_REPO.git)
cd NOM_DU_REPO
3. Configurer les Variables d'EnvironnementCréez un fichier .env à la racine du projet. Ce fichier contiendra votre token d'accès Hugging Face, nécessaire pour télécharger le modèle NLP.touch .env
Ouvrez ce fichier et ajoutez la ligne suivante en remplaçant par votre propre token :HF_TOKEN=hf_xxxxxxxxxxxxxxxxxxxx
4. Lancer l'ApplicationUtilisez Docker Compose pour construire les images et démarrer tous les services en arrière-plan.docker-compose up --build -d
La première fois, le téléchargement du modèle NLP peut prendre plusieurs minutes.
